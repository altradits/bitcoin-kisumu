# Bitcoin Kisumu — Brand Kit

Bitcoin + Lake Victoria. Sunset gold meets lakeside blue.

## Files

| File | Use |
|------|-----|
| `logo.svg` | Primary horizontal lockup — website header, Leaderboard logo (5 pts), docs |
| `logo-stacked.svg` | Centred/stacked — social avatars, flyers, slides |
| `logo-mark.svg` | Icon only — favicon source, stickers, small sizes |
| `logo-mono.svg` | Single-colour (`currentColor`) — print, stamps, footer |
| `favicon.svg` | Browser tab icon (copied to `public/favicon.svg`) |

All are hand-built SVG, no fonts to install. The ₿ glyph uses system Arial/Helvetica bold so it renders everywhere.

## Rules

- Keep the orange ring intact; don't recolour it.
- Minimum digital width: mark 32px, full logo 140px.
- On dark backgrounds use `logo.svg` as-is (navy text won't read — use stacked on a light card, or mono in white).
- Clear space = height of the ₿ glyph on all sides.

## Leaderboard uploads

- Logo upload: use `logo.svg` (export PNG 512×512 if the form needs raster).
- Community photo: still needed — high-quality team photo, see `content/leaderboard-checklist.md`.
